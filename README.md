# Productivity Tracker

MEAN-stack productivity tracker.

## Structure

- `frontend/` — Angular application
- `backend/` — Node/Express API (dependencies installed; add server source under `backend/` as you build the API)

## Quick start

```bash
# Install
npm run install:all

# Frontend (http://localhost:4200)
npm run start:frontend

# Backend — once a server entry point exists:
# npm --prefix backend start
```

See `frontend/README.md` for Angular CLI details.
